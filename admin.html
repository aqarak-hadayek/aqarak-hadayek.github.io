افتح الموقع

اربط اللوحة بحساب GitHub

اللوحة بتحفظ تعديلاتك في مخزن الموقع على GitHub. المفتاح بيتحفظ على جهازك ده بس، ومش بيتبعت لأي مكان غير GitHub.

إزاي تجيب المفتاح

  1. افتح github.com وإنت مسجّل دخول، وروح Settings ثم Developer settings ثم Personal access tokens ثم Fine-grained tokens.
  2. دوس Generate new token، وفي Repository access اختار Only select repositories وحدد مخزن الموقع والمخزن الخاص.
  3. في Permissions افتح Contents وخليها Read and write.
  4. دوس Generate وانسخ المفتاح وحطه هنا.
